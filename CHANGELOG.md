# Changelog — DSO System

## v0.5.1 — Tech Noir UX Stabilization

- Revisão visual integral da build de teste v0.5.0 preservando a identidade Tech Noir DSO.
- Reengenharia dos blocos Nível, NEX, PD/Turno, Deslocamento, Prestígio e Patente.
- Defesa retorna ao card retangular técnico; Vida e Determinação preservadas.
- Seletor próprio DSO para Classe, Origem e Trilha, eliminando o dropdown branco/sem contraste do sistema operacional.
- Benefícios de Origem agora são informados por toast transitório em vez de aviso permanente.
- Dashboard do Inventário em duas linhas: Prestígio/Patente/Crédito e Limites/Carga.
- Aumento global de tipografia funcional e metadados para leitura confortável.
- Editor de registros reorganizado por seções operacionais.
- Nomenclaturas internas de armas convertidas para PT-BR nos controles.
- HTML do Foundry é convertido para texto limpo nos campos de edição.
- Dano Extra redesenhado como componente Tech Noir estruturado.
- Sistema explícito de camadas: biblioteca < editor < modificações/maldições < resultados/toasts.
- Modificações/Maldições agora abre corretamente sobre o editor.
- Escape fecha sempre a camada superior primeiro.
- Mantém persistência Owlbear, catálogo, renderer estável e integrações introduzidas na v0.5.0.
