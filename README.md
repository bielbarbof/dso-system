# DSO System v0.3.0

Extensão de gestão de protagonistas de Ordem Paranormal para Owlbear Rodeo, com interface **Tech Noir DSO** e integração com o **DSO Chat**.

## Núcleo atual

- criação e edição de protagonistas;
- Mestre atribui controlador por jogador;
- Nível e NEX separados;
- PV e Determinação (PD) derivados automaticamente, com ajustes externos editáveis;
- atributos AGI, FOR, INT, PRE e VIG;
- perícias no mesmo padrão visual/funcional da aba + TESTE do DSO Chat;
- rolagens enviadas para o DSO Chat;
- biblioteca estruturada de inventário, habilidades e rituais;
- habilidades organizadas por Poderes de Classe, Trilhas, Origens, Poderes Gerais e Poderes Paranormais;
- origem do livro básico aplica automaticamente suas perícias e poder;
- vínculo de protagonista com token;
- barras de PV/PD no token;
- painel rápido para alterar PV/PD;
- exportação e importação do banco da sala;
- exclusão de protagonista pelo Mestre.

## Compêndio

A v0.3.0 parte do conteúdo estruturado extraído do sistema Foundry fornecido para o projeto e acrescenta uma camada própria de organização e automação. O arquivo `data/compendium.json` contém inventário, habilidades, rituais, regras de origem e uma seção separada de Poderes Paranormais.

Consulte `COMPENDIUM_REPORT.md` para os números e limites atuais do port.

## Atualização

Substitua os arquivos do repositório do DSO System pelos arquivos desta versão, faça commit e aguarde o redeploy do Render. O URL do manifesto permanece o mesmo.
