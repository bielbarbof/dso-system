# Atualizando para DSO System v0.5.1

1. Descompacte `dso-system-owlbear-v0.5.1.zip`.
2. Abra a pasta local do repositório `dso-system` clonada pelo GitHub Desktop.
3. Copie **todos os arquivos e pastas de dentro** da v0.5.1 por cima do repositório local.
4. Confirme a substituição dos arquivos existentes. Não apague a pasta oculta `.git`.
5. No GitHub Desktop, revise as mudanças e use `DSO System v0.5.1` em **Summary**.
6. Clique **Commit to main** e depois **Push origin**.
7. Aguarde o novo deploy do Render e recarregue o Owlbear.

A v0.5.1 usa o mesmo identificador da extensão e mantém o banco persistente da v0.5.0; não é necessário remover/reinstalar a extensão.
